# RallyScope Week 7 — 20-point rubric checklist

- [ ] **Data Loaded & Prepared (4 pts)**: Run `download_data.py` to download **all** records; run `data_audit.py`; keep cleaning report as evidence.
- [ ] **Views Implemented (4 pts)**: Confirm comeback, discipline competitiveness, and rivalry plots display **real BWF match results** with labels and axes.
- [ ] **Encodings Applied (4 pts)**: Check comeback rate → bar length; discipline → category/hue; deciding-game rate → bar height; meetings → X position; parity → Y position; number of deciding games → bubble size. Year/tier are filters. Note any deviations from proposal.
- [ ] **Basic Interaction & Linking (4 pts)**: Click a comeback bar, discipline bar, and rivalry bubble; verify the other views change, tooltips work, and clear selection restores the overview.
- [ ] **Peer Feedback Session (4 pts)**: Attend and demo live; record actual peers/issues/planned changes in the half-page log. Never fabricate this.
- [ ] **Submit**: Repository URL (or ZIP + exact local setup instructions); 1–2 screenshots captured *from the running real-data app*; completed peer feedback log after class.

**Run check:** If the grader cannot execute the app, criteria 2–4 are each capped at 2. Test installation and startup on your own machine before submission.

**Not required yet:** polished multi-directional brushing, final colorblind/greyscale evaluation, Week 8 usability study (2 peers × 3 tasks), and final reflection. They belong to the Week 8 final milestone.
