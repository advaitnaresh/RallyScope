# RallyScope final submission
RallyScope is an interactive badminton dashboard exploring comeback rates, deciding-game frequency, point margins, and rivalry parity.
- [Open the live dashboard](https://advaitnaresh.github.io/RallyScope/)
- [Source code and local setup](../week7/README.md)
- [Recorded prototype video](https://drive.google.com/file/d/1Ug9ia-M7fCxOrZ6MWdCXmtVvEbHpt4y4/view?usp=sharing)
The final design incorporates instructor and peer feedback: preserved comparison context, visible sample sizes, consistent selection color, a separate game-point margin plot, and clearer rivalry axes. The evaluation report, reflection, and annotated interaction screenshots are provided with the course submission.
