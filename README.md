# RallyScope

**Interactive Badminton Performance & Rivalry Analytics**  
Advait Jishnani · NYU Information Visualization

RallyScope studies comeback success after losing the opening game, deciding-game rates across badminton disciplines, and head-to-head rivalry parity.

## Project milestones

- [Week 5 proposal](week5/README.md) — research questions, data plan, and dashboard design.
- [Week 7 working prototype](week7/README.md) — Python Dash app, browser dashboard source, data audit, tests, and screenshots.
- [Submission links and recording](week7/SUBMISSION.md).

## Open the dashboard

**[Launch the interactive browser dashboard](https://advaitnaresh.github.io/RallyScope/).** It loads the full credited source CSV in the browser and supports the same three research views, filters, hover details, and linked chart selections.

To run the Python Dash version locally, follow the [Week 7 setup instructions](week7/README.md). The source CSV is downloaded during setup and is not stored in this repository.

Source: [Sahil Motyar's BWF Match Data](https://github.com/SahilMotyar/bwf-match-data). Underlying match results © BWF. RallyScope is not an official BWF product.
